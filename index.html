구글 시트 연결 안 됨 — 아래 설정에서 연결해 주세요
⚙ 설정 (담당자 · 구글 시트 연결)
다른 핸드폰에서 이 연결 주소를 열면 구글 시트 연결이 자동으로 돼요. 맨 위에서 담당자만 고르면 끝이에요.
처음 한 번: 구글 시트 만드는 방법
  1. 컴퓨터에서 sheets.google.com 접속 → 빈 스프레드시트 만들기 → 제목을 "수액 배달 기록"으로 바꾸기
  2. 위 메뉴 확장 프로그램 → Apps Script
  3. 열린 화면의 원래 코드를 모두 지우고, 아래 코드 복사로 복사한 코드를 붙여넣기 → 💾 저장
  4. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택
  5. 실행 계정: 나, 액세스 권한: 모든 사용자 → 배포
  6. 액세스 승인 → 내 구글 계정 선택 → "확인되지 않은 앱" 화면이 나오면 고급 → (안전하지 않음)으로 이동 → 허용 (내가 만든 코드라 괜찮아요)
  7. 나오는 웹 앱 URL을 복사해서 위 "구글 시트 연결 주소" 칸에 붙여넣기
